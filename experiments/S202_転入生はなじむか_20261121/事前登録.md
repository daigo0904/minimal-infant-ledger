# S202 転入生はいずれ輪に入れるか（なじむ速さ）

S201：転入生は来てから1000手、古株よりなぐさめが届かず誰かの一番に選ばれにくい。
作り：S201 の世界・頭をそのまま読む（数え.py）。γ0・β0.3・kG1。2000・3000・4000・5000手に 子0〜3 を順に新しい子に。
測る：各転入生の 来てから 0〜1000／1000〜2000／2000〜3000 手の なぐさめてもらった回数・入り次数 を、同じ時間の古株（一度も入れ替えない 子4〜7）の平均と比べ（転入生−古株）、4人の平均。
- 調整（選び.log・種900〜909）：なぐさめてもらった差 −77／−71／−94、入り次数の差 −0.84／−0.66／−0.44。縮む（2000〜3000 > 0〜1000）なぐさめ 8/10・入り次数 9/10、2000〜3000 でも不利 7/10。
- 見込み：入り次数（輪に入る）はだんだん縮む。なぐさめの届き方の縮みは弱い。3000手たっても不利は残る。
- 種：本 42000〜42029、追試 42100〜42129（未使用）。腕：1つ（γ0）。
- H1 輪になじむ：入り次数の差 2000〜3000 > 0〜1000 が 20/30 以上
- H2 なぐさめも届くようになる：なぐさめてもらった差 2000〜3000 > 0〜1000 が 20/30 以上
- H3 なじみきらない：2000〜3000 の なぐさめてもらった差 < 0 が 20/30 以上
