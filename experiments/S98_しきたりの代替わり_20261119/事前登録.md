# S98 意味のないしきたりは、代替わりしても残るか

世界.py＝S95 世界の写しに 代替わり：4000 手から 500 手ごとに赤ちゃん0,1,…,7 を順に生まれたてに入れ替える（種+300000）。入れ替わった子にはしきたりを強いない。
しきたり：2000 手から（まだ入れ替わっていない）赤ちゃん0〜6 が「しきたりの手」（当たりとは違う手＝食べ物は出ない）／でたらめな手をする。7500 で最後の子が入れ替わり、以後しきたりを強いられる子はいない。
当たり固定・手16・一層・学び率0.05・寿命10000。
- 腕：しきたり（決まった手／でたらめ）× 仲間が褒める／褒めない。
- 確かめ（種23299）：2000〜4000 で0〜6 が全部しきたり ○、4000〜4500 で1〜6 が全部しきたり ○、6500〜7000 で6 が全部しきたり ○、入れ替わった0 は全部しきたりではない ○、7500〜 で強いられる子がいない ○、4腕が違う（sha）○。
  確かめの1世界では 8500〜 全員のしきたり率 0.034（でたらめなら 1/16=0.063）、当たり率 0.336。
- 測る：8500〜10000 の全員（8人とも強いられたことのない子）がしきたりの手をする割合。効き＝決まった手 − でたらめ。
- 種：本 23000〜23029、追試 23100〜23129（各30世界・未使用）。
- H1 しきたりが代替わり後も残る：褒めるで 効き > 0 が 20/30 以上
- H2 褒めないと残らない：効き 褒めない < 褒める が 20/30 以上
- 勝ったら：しきたりは強いる者がいなくなっても承認だけで世代をまたぐ。負けたら：S95 の伝わりは「強いている仲間がいる間だけ」で、文化として自立はしない。
