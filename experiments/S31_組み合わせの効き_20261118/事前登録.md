# S31 組み合わせの効き（2×2）

S30 の「換算型×その手だけで漏れが減る」に、同じ種の元の頭の対照が無い（S16 は別の種）。
- 2×2：頭（元の獲得型／換算型 c=30）× 給餌（持ち越す／その手だけ）。S16 世界・感覚256・雑音0.3・寿命8000・離乳8000・依存。
- 種：本 9600〜9609、追試 9700〜9709（未使用）。10世界中8以上で○。
- 漏れの減り＝育った後(7000〜8000)の P他（持ち越す − その手だけ）。
- H1 組み合わせの効き：漏れの減り 換算 > 元
- H2 世界だけの効き：元でも漏れの減り > 0
- 読み：H1○H2× → 組み合わせで効く。H1×H2○ → 世界だけで効き、S30 の教材の文は誤り。
