# S113 つながりの項（u·ê）は、視線と手をどう結んでいるか（記録の診断）

なぜ：S112 で、養育者の視線追いは Q ではなく つながりの項（c·v食·u·ê）から出ていた。どの部分が視線の手を推すのかを記録で見る。
作り：S109 の作り（本物・手4・lr0.01・寿命8000）に、選ぶたびに ê（手ごとの評価の予測）・u（つながり）・q を記録するだけ（手は変わらない＝sha 一致を確かめる）。
- 測る（7000〜8000・養育者が見ている手）：ê[a] − 好み[a]（本当の平均の評価からの上ぶれ）を 視線の手／他の手で、u の平均（養育者の前・仲間の前）、
  u·ê の 視線の手 − 手の平均（項が視線の手を推す大きさ。c·v食 は正の定数なので除く）。8人の平均を1世界の値にする。
- 判定は下の確かめを見る前にコードに書いた。
- 確かめ（種26799）：記録つきは S109 と同じ sha ○、記録が 7999 手目まで埋まる ○。
  1世界：ê上ぶれ 視線の手 −0.003・他 −0.005、u 養育者 −0.011・仲間 −0.030、項の上乗せ +0.041（u が負なのに視線の手を推している）。
- 種：本 26600〜26629、追試 26700〜26729（各30世界・未使用）。
- H1 視線の手の評価の予測が高く出る：ê上ぶれ 視線の手 > 他の手 が 20/30 以上
- H2 養育者へのつながりが正：u 養育者 > 0 が 20/30 以上
- H3 u·ê が視線の手を推す：項の上乗せ > 0 が 20/30 以上
