# S100 「多数に合わせる」頭なら、しきたりは代替わりしても残るか（同調伝達）

なぜ：S99 ××。S99/診断2.log：入れ替わった子のしきたりは強いる仲間の割合にほぼ比例して下がる（kM=2：1人目 0.78 → 5人目 0.38 → 7人目 0.07）。
S99/診断3.log：合わせると得をする世界（仲間へ）でも残らず、一番多い手でも 0.15〜0.21＝そもそも習わしがそろわない。
写す頭は「たまたま見た1人の直前の手」に寄せる＝偏りのない伝わり。文化進化の知見では、習わしを安定させるのは多数派を割合以上に選ぶ同調の偏り。
頭.py＝S99 写す頭に 多数：寄せる先を「これまで見た手の速い頻度（α多数=0.02）の一番多い手」にする。多数=False なら S99 と同じ。
- 調整（種 900〜909 のみ・選び.log）：代替わり後のしきたり 決まった／でたらめ
  仲間へ：写す kM2 0.041/0.043（0/10）、多数 kM2 0.469/0.028（10/10）、多数 kM5 0.514/0.021（10/10）
  流行り：写す kM2 0.037/0.027（0/10）、多数 kM2 0.389/0.015（6/10）、多数 kM5 0.492/0.020（10/10）→ kM=5 を使う。
- 作り：S98 と同じ代替わり（2000〜 しきたり、4000〜 500手ごと、寿命10000、褒める）。世界：流行り（当たり固定＝しきたりは食べ物を損する）／仲間へ（切替=0＝見ている子と同じ手なら食べ物＝合わせると得）。
- 腕：世界 2 × 頭（写す／多数）× しきたり（決まった手／でたらめ）＝8腕。kM=5。
- 確かめ（種23599）：多数=False は S99 写す頭と同じ sha ○、両世界で 2000〜4000 全部しきたり ○、7500〜 強いる子なし ○、8腕が違う ○。確かめの1世界の多数：8500〜 しきたり 流行り 0.465、仲間へ 0.539。
- 測る：8500〜10000 の全員がしきたりの手をする割合。効き＝決まった手 − でたらめ。
- 種：本 23400〜23429、追試 23500〜23529（各30世界・未使用）。
- H1 損の世界で多数なら残る：流行りで 多数の効き > 0 が 20/30 以上
- H2 損の世界で多数のほうが残る：流行りで 効き 多数 > 写す が 20/30 以上
- H3 得の世界で多数なら残る：仲間へで 多数の効き > 0 が 20/30 以上

- 勝ったら：しきたりが世代をまたぐには「多数に合わせる偏り」が要る（1人を写すだけでは消える）。損な習わしでも多数に合わせると残る。負けたら：調整の種だけの当たりだった。
