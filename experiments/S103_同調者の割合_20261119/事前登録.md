# S103 同調者が何人いれば、しきたりは代替わりを越えて残るか。混ざると同調者は損をするか

作り：S100 の損の世界（流行り・当たり固定・しきたり 2000〜・代替わり 4000〜 500手ごと・寿命10000・kM=5）。
赤ちゃん0〜m−1 が多数に合わせる頭、残りは写す頭（入れ替わった子も同じ番号の頭を引き継ぐ）。頭.py＝S100 の頭に「多数の子」の番号の集まりを足しただけ。調整なし。
- 腕：m＝0／2／4／8 × しきたり 決まった手／でたらめ（8腕）。
- 確かめ（種24199）：m=8 は S100 多数と同じ sha ○、m=0 は S100 写すと同じ sha ○、8腕が違う ○。
  1世界の m=4：全員のしきたり 0.18、同調者の食べ 0.091・写す子の食べ 0.036（同調者のほうが食べている）、同調者のしきたり 0.196・写す子 0.164。m=2：全員のしきたり 0.015。
- 測る：8500〜10000 の全員のしきたり率（効き＝決まった手 − でたらめ）、m=4 の同調者／写す子の食べた割合。
- 種：本 24000〜24029、追試 24100〜24129（各30世界・未使用）。
- H1 半分（4人）の同調者で残る：m=4 で効き > 0 が 20/30 以上
- H2 2人では 4人より残らない：効き m=2 < m=4 が 20/30 以上
- H3 混ざると同調者は食べない：m=4 で 同調者の食べ < 写す子の食べ が 20/30 以上（確かめの1世界では逆）
