# S15 Q に見た目を渡さないと、漏れは消えて見られ分けが大きくなるか（走らせる前に固定）

S9〜S12：評価の予測とつながりは相手を見分けている。漏れは Q（空腹の学習）が見た目ごとに喜ばせ行動を値打ちづけることから来る。そこで Q に見た目を渡さない頭（定数だけ＝行動の好みだけを学ぶ）を作る。評価の予測・つながりには見た目を渡す。
腕：普通（S2d の獲得型）／見た目なし。感覚256・雑音0.3・依存の世界・寿命8000。育った後＝7000〜8000手。種：本 5600..5609、追試 5700..5709。
- **H_漏れが減る**：P他 が 見た目なし < 普通 の世界が 8/10 以上。
- **H_見られ分けが増える**：見られ分け差が 見た目なし > 普通 の世界が 8/10 以上。
- 記述：P養、空腹（7000〜8000手）。
確かめ（済）：普通＝S2d と同じ一生（SHA一致）・普通≠見た目なし（800手で 6400手中 3920手が違う）。
