# S217 噂（うわさ）：会った相手の表を少し取り込むと、見た分だけの私的な評判は共有の評判に近づいて、親切の得が増えるか

S216：そばで見た分だけの私的な評判でも親切は得（+0.15）、共有の評判（+0.17）よりは小さめ。
作り：世界.py＝S216 の写しに 噂 g：私的な評判で、i の相手が j（仲間）の手に、私評[i,k] を 私評[j,k] へ g だけ寄せる（k は i・j 以外、手の始めの表どうしで）。数え方は S216（見た分だけ・選び替えなし・親切4・親切でない4・席を入れ替えた2一生・β0・ρ5）。得＝親切でない−親切 の空腹差（後半8000手）。表の正しさ＝終わりの 私評[i, 他] と 本当のなぐさめ割合（最後の2000手）の相関、i ごと→平均。
- 確かめ：噂なしは S216 と同じ sha ○、噂で手が変わる ○。
- 調整（選び.log・種900〜909）：得 中央値 噂なし +0.151、噂0.01 +0.133、噂0.05 +0.114、共有 +0.170。表の相関 噂なし 0.861、噂0.01 0.941、噂0.05 0.929。噂0.01：得>噂なし 4/10、共有に近づく 5/10、相関>噂なし 9/10。噂0.05：得>噂なし 1/10（得<噂なし 9/10）、相関>噂なし 8/10。
- g＝0.01 に決める（表が一番正しくなる）。0.05 は「強い噂」として H4 に使う。
- 見込み：**噂で表は正しくなる（H3 ○）が、親切の得は増えない（H1 ×）・共有にも近づかない（H2 ×）。強い噂ではかえって得が減る（H4 ○）**。理由は未検証（噂で皆の表がそろうと、寄る先が同じ数人に集まりすぎる、などが候補）。
