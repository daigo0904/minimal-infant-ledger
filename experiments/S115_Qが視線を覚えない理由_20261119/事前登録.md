# S115 本物の視線追い（視線と自分の手を直接結ぶ）を Q が覚えない理由（調整の種だけの診断・本計測なし）

数え方：手 x ごとに P(手=x | 養育者の視線=x) − P(手=x | 視線≠x)（持ち上がり）。手の好き嫌いの偏りを打ち消すため（選び.log の「割合」は Q の手の偏りを映していたので、選び2.log で数え直した）。
- 選び2.log：7000〜8000 だけ Qだけ にすると持ち上がりは −0.07〜+0.04（そのままは端の手 +0.45〜+0.53）。学び率 0.01／0.05／0.2・視線を直に足す あり／なし のどれでも育たない
  → 見当「φ·φ で割るので歩幅が小さい」は外れ（学び率 20倍でも同じ）。
- 選び3.log：一生ずっと Qだけ で選ぶ子でも持ち上がり +0.007〜+0.026。視線の手で食べる 0.155 対 それ以外 0.010（15倍）なのに育たない。
- 選び4.log：食べたこと自体を報酬に足す（k）と少し育つ：k=1 で +0.081（lr0.01）・+0.061（lr0.05）、k=0 は +0.013。
  → 空腹だけの報酬では食べ物の手応えが小さい（1回食べても R の差は 0.03 ほど）のが一因。ただし k=1 でも小さく、全部は説明しない。
- 未確認：感覚の層を通った φ から「視線＝手 a」が線形に読めるか（表す力の限界か、学び方の限界か）。次に確かめる。
