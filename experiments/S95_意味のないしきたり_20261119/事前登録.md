# S95 意味のないしきたりは、仲間の承認だけで新入りに伝わるか

世界.py＝S94 世界の写しに しきたり：4000 手から仲間（赤ちゃん0〜6）がいつも「しきたりの手」（当たりとは違う手＝食べ物は出ない）をする／でたらめな手をする。4000 で赤ちゃん7 が新入り。当たり固定・手16・一層・学び率0.05・寿命6000。
- 腕：しきたり（決まった手／でたらめ）× 仲間が褒める／褒めない。
- 確かめ：しきたりの手≠当たり、4000〜 仲間は全部しきたりの手、4000 前は違う、しきたりの手で食べた割合 0.009（基本だけ）、4腕が違う（sha）。
- 測る：新入り（赤ちゃん7）がしきたりの手をする割合（4500〜6000）。効き＝決まった手 − でたらめ。
- 種：本 22400〜22429、追試 22500〜22529（各30世界・未使用）。
- H1 しきたりが新入りに伝わる：褒めるで 効き > 0 が 20/30 以上
- H2 褒めないと伝わらない：効き 褒めない < 褒める が 20/30 以上
