# S172 v7（v4＋見て学ぶ 代理3）は、見本の無い世界では v4 と同じ手か

見て学ぶ部品（S168）は「見本」がある世界でしか働かない（子.見本 が無ければ何もしない）。S166 の7つの章の世界には見本が無い。
→ v7 の手が v4 と全く同じ（sha 一致）なら、v7 は v4 がこれらの章で出したもの（S152・S159・S166 の v4 の数字）をそのまま持ち、加えて見て学ぶ（S168）を持つ。この場合、章ごとの本計測は要らない（同じ手なら同じ数字）。
- 確かめ：7つの世界（48・64・116・122・125・150・164）× 種 3つ（900・901・902）、本番の寿命（8000手、164 は 4000手から知らない大人）で、v7 と v4 の sha が 21組すべて一致すれば ○。1組でも違えば、どこで違うか調べる。
- 頭は S168 の v2.py（世界164 も頭を差しかえる）。v4 は同じ v2 で 代理0、v7 は 代理3。どれも別の処理で読む。
- 対照：同じ道具で 違う頭（v4 と 元）なら sha が違うこと（21組すべて違う）＝道具が「何でも同じ」と言わない確認。
