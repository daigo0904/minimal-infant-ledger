# S229 自分の耳で話す（聞いて分かる言い方で話す）と、仲間の言い方はそろうか

S228：一人ひとりの言い方ははっきり（0.78 ビット）だが、仲間でそろわない（まとめると 0.14）。
作り：世界.py＝S228 の写し（毎回組み替え）に 話し方＝'耳'：話し手は、自分が聞き手として合図 c を聞いたら場所 L を選ぶ値（v4 の手の点＝λ·Q＋kf·(食べ予測−平均)、同じ頭に聞き手の入力を入れて読む）が一番高い c を出す。乱数［種,42］で 0.1 はでたらめ。それ以外（学び方・共感）は同じ。
測るもの（後半8000手）：当たり率、全体の結びつき、話し手ごとの結びつき、言い方の一致（2人の子の 場所→一番多い合図 が同じ割合を28組で平均・偶然 0.25）。
- 確かめ：ふつうは S228 と同じ sha ○、耳で手が変わる ○。
- 調整（選び.log・種900〜909）中央値：ふつう 当たり 0.367・全体 0.155・話し手ごと 0.762・一致 0.290、耳 0.858・1.499・1.501・1.000（10世界とも一致 1.0）。耳>ふつう 全体・当たり・一致 とも 10/10。
- 足した対照：耳・共感なし（kE0）、耳・聞き手も見える。**注意**：耳で話すは「聞いて分かるように話す」という決まりを頭に入れた口なので、話し手に伝える得（共感）が無くても言葉ができるかもしれない（H4）。そうなら、この口は「話す理由」を飛ばしている。
- 見込み：耳で全体の結びつき・当たり・一致が大きく上がる（H1〜H3 ○）。共感なしでも耳なら言葉ができる（H4 ○＝話す理由は要らなくなる）。聞き手も見える世界では、聞き手が合図に頼らないので耳でも言葉は弱い（H5 ○）。
