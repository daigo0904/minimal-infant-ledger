# S238 話し手と聞き手の得がぶつかる世界では、言葉はうそになって崩れるか

言葉の章は、話し手と聞き手の得が一致する世界（聞き手が食べると話し手も共感でうれしい）で進めた。得がぶつかったら？
作り：世界.py＝S232 の写し（4か所・毎回組み替え・共感 kE50）に 競う：聞き手が外したら、話し手がそのご飯を食べる。話し方はふつう（自分の点で選び自分で学ぶ）。耳で話す口は使わない（決まりで正直になるので）。協力（S232 と同じ）／競う。
- 確かめ：協力は S232 と同じ sha ○、競うで手が変わる ○。
- 調整（選び.log・種900〜909）中央値：協力 当たり 0.367・全体 0.155・話し手ごと 0.762、競う 0.251（10世界とも 0.24〜0.26）・0.018・0.617。当たり 競う<協力 10/10、競う<0.25 4/10、話し手ごと 競う<協力 10/10、全体 10/10。
- 見込み：得がぶつかると言葉は崩れて当たりは偶然に落ちる（H1・H4・H5 ○）。話し手ひとりひとりの言い方も弱まる（H3 ○）。ただ「だまされる」（偶然より下）までは行かない（H2 ×）＝聞き手が合図を当てにしなくなるので、うそは効かなくなる。
- 種：本 49200〜49229、追試 49300〜49329（未使用）。
- H1 競うと当たらない：当たり 競う < 協力 が 20/30 以上（見込み ○）
- H2 だまされる：競うで 当たり < 0.25 が 20/30 以上（見込み ×）
- H3 話し手の言い方も弱まる：話し手ごとの結びつき 競う < 協力 が 20/30 以上（見込み ○）
- H4 言葉が崩れる：全体の結びつき 競う < 協力 が 20/30 以上（見込み ○）
- H5 ほぼ偶然：競うで |当たり−0.25| < 0.02 が 20/30 以上（見込み ○）
