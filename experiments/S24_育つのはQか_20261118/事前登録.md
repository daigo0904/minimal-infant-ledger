# S24 育つのは Q の分か

S23 の記述（獲得型−道具型 の差が 初め0.07→育った後0.04〜0.07 で広がらない、道具型も 0.01→0.13〜0.17 と育つ）を新しい種で確かめる。

- 頭：S2d・感覚256・見た目雑音0.3。寿命8000・離乳8000・依存の世界。腕：獲得型／道具型（同じ種＝同じ世界）。
- 数：見られ分け（養育者が見ている時と他の子が見ている時の「一番好かれる手」の割合の差）。初め＝0〜500、育った後＝7000〜8000。
- 種：本 8200〜8209、追試 8300〜8309（未使用）。
- 判定（10世界中8以上で○、本・追試とも○で支持）
  - H1 差が育つ：（獲得型−道具型）が 初めより育った後で大きい
  - H2 道具型も育つ：道具型で 初め ≤ 育った後の半分
- 読み：H1× かつ H2○ なら「つながりの分は初めからあり、育つのは Q の分」。H1○ ならつながりの分も育つ。
- 確かめ：獲得型と道具型で一生が違い、相手の並びは同じ。
