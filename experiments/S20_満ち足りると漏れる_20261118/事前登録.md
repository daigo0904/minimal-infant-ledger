# S20 空腹の状態ごとに、漏れを出しているのは Q かつながりか（診断・直さない・走らせる前に固定）

S19 の 一つ128体（見た目＋体）を同じ種（本 6600..6609、追試 6700..6709）で 8000手育てて止める。各赤ちゃんに、他の子の見た目（雑音0.3）と、体＝空腹 h ∈ {0.3, 0.6, 1.0}・直前に食べた=0・直前の評価=0・直前の行動=4通り（平均する）を組み合わせて各 h で 280回見せ、選び方3通りで「養育者の一番」を選ぶ割合を数える：Qだけ（argmax Q）・つながりだけ（argmax 2·つながり·予測評価）・両方。
- **H_満ち足りると Q が漏らす**：Qだけ の割合（10世界の中央値）が h=0.3 で h=1.0 より 0.1 以上大きい。
- **H_満ち足りるとつながりが漏らす**：つながりだけ で同じ。
- 記述：各 h の3通りの割合、養育者の見た目での同じ数字。
