# S14 探りを増やすと、取り違え（漏れ）が減るか（走らせる前に固定）

S2d の世界.py・感覚256・雑音0.3・依存の世界・獲得型・寿命8000。探り（でたらめに選ぶ割合）を 0.1（今）と 0.3 で比べる。探りの手は一様に選ぶので P他 を 0.25 に寄せてしまう。そこで行動の記録とは別に、毎手「探らなければ選んだ行動」（貪欲な行動）を記録し、育った後（7000〜8000手）の P他・見られ分け差をその貪欲な行動で数える。
種：本 5400..5409、追試 5500..5509。
- **H_漏れが減る**：貪欲な行動での P他 が 0.3 < 0.1 の世界が 8/10 以上。
- **H_見られ分けが増える**：貪欲な行動での見られ分け差が 0.3 > 0.1 の世界が 8/10 以上。
- 記述：実際の行動で数えた値も並べる。
走らせる前の確かめ：探り0.1 のとき、この記録つきの選び方は S2d と同じ一生（SHA一致）。
確かめ（済）：記録つき＝S2d（SHA一致）・0.1≠0.3。
