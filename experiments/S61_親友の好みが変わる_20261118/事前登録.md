# S61 親友の好みが変わったら、その人のぶんだけ直せるか

世界.py＝S59 世界の写しに 親友替え：その手から親友の好きな手（評価も給餌も）を好みの3番目の手に替える。養育者は変わらない。寿命12000。本物の頭（S59 と同じ作り）。
- 腕：替える（8000 から）／替えない。同じ種。
- 確かめ：8000 まで同じ一生、8000〜で違う。親友の前で旧の手の食べた割合 0.152→0.009、新の手 0.009→0.193（発火）。
- 種：本 15600〜15629、追試 15700〜15729（各30世界・未使用）。測る窓＝11000〜12000。
- H1 新しい手に替える：替えるで P(新|親友) > P(旧|親友) が 20/30 以上
- H2 養育者のぶんは壊れない：替えるの（P(一番|養育者) − P(一番|他の子)）≥ 替えないの 0.9倍 が 20/30 以上
- H3 親友の前でだけ変える：替えるで P(新|親友) − P(新|他の子) > 0 が 20/30 以上
