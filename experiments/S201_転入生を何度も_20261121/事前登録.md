# S201 転入生を何度も入れて見分ける力を上げる

S200：転入生が取り残されるかは割れた（子ごとのばらつきが転入の効き目より大きい）。
作り：世界.py＝S200 の写しで 転入に (手, 子) の並びを渡せる。3000・4000・5000・6000・7000手に 子0〜4 を順に新しい子（頭・顔とも新しく、顔は乱数[種,32,子]）に。
測る：各転入生の来てから1000手の なぐさめてもらった回数・入り次数（誰かの一番に選ばれた数）を、同じ1000手の古株（2000手より前からいる子）の平均と比べ（転入生−古株）、5回の平均。同じ時間の中で比べるので世界の違いが消える。
- 確かめ：入れ替えなしは S199 と同じ sha ○、1人だけの転入（700）は S200 と同じ sha ○。
- 調整（選び.log・種900〜909）：なぐさめてもらった差（<0）／入り次数の差（<0）：γ0 −110（10/10）／−0.45（8/10）、γ5 −144（10/10）／−0.35（7/10）。γ5 で不利が小さい なぐさめ 5/10・入り次数 6/10。
- 見込み：転入生はなぐさめが届かず輪に入りにくい。困っている子に寄っても転入生は助からない（転入生はまだ困っていると見られない／恩が無いので寄られない）。
- 種：本 41800〜41829、追試 41900〜41929（未使用）。腕：γ0／γ5（β0.3・kG1・転入あり）。
- H1 転入生になぐさめが届かない：γ0 で なぐさめてもらった差 < 0 が 20/30 以上
- H2 転入生は一番に選ばれにくい：γ0 で 入り次数の差 < 0 が 20/30 以上
- H3 困っている子に寄る世界でも届かない：γ5 で なぐさめてもらった差 < 0 が 20/30 以上
- H4 困っている子に寄ると転入生が助かる：なぐさめてもらった差 γ5 > γ0 が 20/30 以上（見込み ×）
