# S208 親切が損な世界なら、世代の入れ替わりで親切は減るか（S205 のやり直し）

S205：恩人に寄る世界（β0.3）では親切は減りも広がりもしない（S206：そもそも損でない）。S207：寄らない世界（β0）では親切は損（感謝で半分ほど埋まる）。
作り：S205 の世界・頭をそのまま読む（数え.py）。β0・寿命16000・選び替え 2000手から250手ごと（56回）：直近250手で一番お腹を空かせた子→新しい子、型は一番お腹の空いていない子から。はじめ 子0〜3 が親切（共感3倍）。
対照：印だけ（親切1倍＝共感は強めず、型の印だけ受け継ぐ）＝損得の無い時の漂流。
測る：終わりの親切（印）の数＝最後の8回（2000手ぶん）の平均、中ほど（8000手ごろ）。
- 調整（選び.log・対照.log・種900〜909）：kG0 終わり 0（10/10 が 0）・中ほど 0、kG1 終わり 0（10/10）・中ほど 0。対照（印だけ・kG1）終わり 8・8・8・8・7・0・0・0.9・0・0（偶然で 8 か 0 に固まる）。
- 見込み：損な親切はふるい落とされて消える。感謝があっても消える（減り方も変わらない）。対照では消えない世界が半分ほど。
- 種：本 43200〜43229、追試 43300〜43329（未使用）。腕：kG0／kG1／対照（kG1・親切1）。
- H1 感謝なしで親切は減る：kG0 で 終わり < 4 が 20/30 以上
- H2 感謝ありでも親切は減る：kG1 で 終わり < 4 が 20/30 以上
- H3 損のせい（対照）：対照で 終わり > kG1 の終わり が 10/30 以上（対照は偶然で 8 か 0 になるので、損が無ければ半分ほどは親切の腕より多い）
