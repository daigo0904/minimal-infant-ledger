# S43 切って測る効きの対照（無関係の世界）

S42 の作り（A 切らない／B 0〜500 だけ切る／C 7000〜8000 だけ切る、v時定数5000・Q 学び率0.01・換算 c=30・その手だけ・S16 世界）を、依存の世界と無関係の世界（給餌が見られ方と無関係）で同じ種で。
- 発火の確かめ：無関係でも B は 0〜500 で違う、C は 7000手まで同じで 7000〜 で違う。依存≠無関係（sha）。
- 種：本 12000〜12029、追試 12100〜12129（各30世界・未使用）。
- H1 無関係では小さい：効き 育った後 無関係 < 依存 が 20/30 以上
- H2 無関係では育たない：無関係で 効き 初め ≥ 育った後 が 20/30 以上
- 参考：依存で効きが育つ数
