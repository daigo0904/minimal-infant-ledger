# S101 多数に合わせる頭には代価があるか（当たりが 1000手ごとに替わる世界）

なぜ：S100 ○○○○。多数に合わせると しきたりが残る。文化進化の知見では、同調は「世界が変わると古い習わしに縛られる」代価を持つ。この箱でもそうか。
作り：S100 の頭と世界（しきたり・代替わりなし）。給餌の形='流行り'（当たりは 1000手ごとに替わる＝当たり固定なし）・手16・寿命10000・褒める。調整するつまみは無い（kM=5 は S100 のまま）。
- 腕：換算（kM=0）／写す（kM=5・見た手）／多数（kM=5・見た手の頻度の一番）。
- 確かめ（種23799）：3腕が違う（sha）○。1世界の 2000〜 食べ・切替直後200手の新しい当たり・古い当たり・当たり：換算 0.029/0.049/0.175/0.13、写す 0.039/0.091/0.195/0.199、多数 0.025/0.030/0.182/0.103。
- 測る：2000〜10000 の食べた割合（全員）、各切替（2000,3000,…,9000）の直後200手で新しい当たりをした割合。
- 種：本 23600〜23629、追試 23700〜23729（各30世界・未使用）。
- H1 多数は写すより食べない：20/30 以上
- H2 多数は換算より食べない：20/30 以上
- H3 多数は切替直後の新しい当たりが写すより少ない：20/30 以上
- 勝ったら：同調には「世界が変わると遅れる」代価がある（S100 の利点と対）。負けたら：この箱の同調は変わる世界でも損をしない。
