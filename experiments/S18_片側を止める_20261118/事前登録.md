# S18 片側を止めると何が壊れるか（走らせる前に固定）

指示の作りの訂正：右＝相手の見た目・左＝自分の体 に分けると、見た目を見るのは右だけなので「右を止めると見られ分けが消える」は作りから決まる。そこで左右とも見た目を見る形にする：**右＝見た目の符号だけ（ざっくり・全体）64**、**左＝見た目そのまま＋自分の体（空腹・直前に食べたか・直前の評価・直前の行動）64**。左右は別々に学ぶ（S17b の 別々 が土台）。行動は左右の値の和。
8000手まで同じに育て、8000〜9000手を3通りで続ける：**止めない**／**右を止める**／**左を止める**（止めた側は値を出さず、学ばない）。8000手までは3つで同じ一生（確かめ済み）。S2d の世界・雑音0.3・依存・獲得型・離乳なし。種：本 6400..6409、追試 6500..6509。
- **H**：8000〜9000 の見られ分け差が 右を止める < 左を止める の世界が 8/10 以上（人では右の損傷で顔の見分けが落ちやすい、に合う向き）。
- 記述：P養・P他・空腹、止める前（7000〜8000）。
確かめ（済）：止める前は3つで同じ行動列・止めた後は3つとも違う一生。
