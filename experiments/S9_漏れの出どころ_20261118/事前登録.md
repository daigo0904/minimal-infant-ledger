# S9 漏れ（他の子に見られていても喜ばせる）の出どころ（診断・直さない・走らせる前に固定）

依存の世界・獲得型・寿命8000・離乳8000。感覚は2通り：**固定**（S4 の両方＝乱数 tanh 256・見た目の雑音0.3）と **育つ**（S8 の型16個の競合学習・雑音0.3）。8000手で頭を止め（学ばない）、各赤ちゃんに 養育者の見た目 と 他の子の見た目 を雑音つきで各200回見せ、3通りの選び方で「養育者の一番好きな行動」を選ぶ割合を数える：
- **Qだけ**：argmax Q(見た目)
- **つながりだけ**：argmax 2·つながり(見た目)·予測評価
- **両方**：本番と同じ（探りなし）
種：本 4400..4409、追試 4500..4509。中央値で判定：
- **H_Qが漏らす**：他の子の見た目で Qだけ の割合 ≥ 0.4。
- **H_つながりが漏らす**：他の子の見た目で つながりだけ の割合 ≥ 0.4。
- 記述：つながりの値（養育者・他の子の見た目それぞれの平均）、他の子の見た目での予測評価の 一番 − 他の平均。
