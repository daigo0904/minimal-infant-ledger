# S161 人ごとの信頼 τ を足す（調整で×・本計測なし）

作り：v2.py＝S158 の写しに kτ：食べ予測の答え合わせのたびに 外れ＝|y − f̂[a]|、手応え＝（外れの平均 − 外れ）を RLS τ(φ) で予測し、食べ予測の項に max(0, 1+kτ·τ) を掛ける。kτ=0 は S153・S160 と同じ sha ○（36fb8e50・2a01b9e9）。
調整（選び.log・種900〜909・S160 世界）：後半の初めの合図2に従う差 1.0/0.5：kτ0 +0.102/+0.103（7/10）、10 +0.078/+0.075（5/10）、50 +0.042/+0.013（4/10）、200 +0.031/+0.037（6/10）。kτ を上げるほど全部下がり、持ち越しは出ない。
診断（診断.log・kτ10・種900〜907）：τ 3000〜4000 養育者 +0.037／物知り −0.014（1.0）・−0.017（0.5）／ほか −0.016。後半 4000〜4500 は全員 −0.06〜−0.14 に落ちる。
→ 2つの穴：(1) 新しい入力の次元で τ が相手を問わず大きく負に外れ、掛け算が 0 に切られて食べ予測が消える。(2) 物知り（会うのは約6%）の当たり外れの差が、食べ物の偶然に埋もれて τ に出ない（養育者とほかは分かれる）。
本計測は走らせない（部品が狙いの物を学んでいないので、測っても部品の効果にならない）。次（S162）で (1) 顔だけから τ を読む (2) 物知りに会う回数を増やす、で直してから測る。
