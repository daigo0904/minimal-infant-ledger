# S1 見られ方の恒常性 — 「相手からどう見られたいか」を空腹と同じ形で持たせる

2026-11-18 登録（走らせる前）。本人の指定：相手は **養育者1人＋ほかの赤ちゃん7人**、目標値は **生まれつき と 育ちで の両方を比べる**、最初の問いは **そもそも効くか**（空腹との衝突はまだ入れない）。

## 世界

- 1つの世界に赤ちゃん8人（全員が同じ条件のAI）＋養育者1人。寿命 T=6000 手。
- 毎手、各赤ちゃんに「見ている相手」を1人引く：確率0.5で養育者、残りは自分以外の赤ちゃん7人から一様。赤ちゃんは誰が見ているかを知ってから行動する。
- 行動は4つ（a=0..3、意味づけはしない）。8人は同時に動く。
- 見ている相手の評価 e（−1..1 に切る）：
  - 養育者：好み pref[a]（世界ごとに [−0.8, −0.2, 0.3, 0.9] を並べ替えた固定値）＋雑音 N(0, 0.2)。
  - 赤ちゃん j：自分（j）の直前の行動と同じなら +0.8、違えば −0.4、＋雑音 N(0, 0.2)。
- 見られ方 r：受けた評価の移動平均 r ← r + (e − r)/50。r の初期値0。

## 頭（全条件で同じ）

- 予測器：RLS（忘却0.9995・P初め100）。入力は [見ている相手(8)×行動(4) の one-hot 32] ＋ [相手が赤ちゃんで、行動が相手の直前の行動と同じ 1] ＋ 定数1 ＝ 34。評価 e を予測する。※赤ちゃんは相手の直前の行動が見えるという仮定。リザバーは使わない（最初の安い機構試験のため）。
- 恒常性で選ぶ：各行動の予測 ê で、次の r' = r + (ê − r)/50 を出し、(r' − r*)² が最小の行動を選ぶ（空腹の D15 と同じ「予測した次の状態の偏差の二乗を最小」）。確率0.1で一様に探る。
- 対照（そっくり同じ頭・同じ学習）：行動は常に一様ランダム。予測器は学ぶが行動に使わない。

## 4つの条件（世界ごとに同じ種＝同じ養育者の好み・同じ見る相手の順番・同じ雑音）

- **A 生まれつき**：r* は生まれつき固定。8人に −0.6〜0.8 の等間隔8値を種で並べ替えて配る。
- **A0**：A と同じ r*、行動はランダム。
- **B 育ちで**：r* の初期値0、r* ← r* + (r − r*)/2000 で毎手ゆっくり r に寄る（受けてきた見られ方が目標になる）。
- **B0**：B と同じ r* の育ち方、行動はランダム。

## 測るもの（最後の1000手）

- 偏差 D = 世界の8人の平均 (r − r*)²（毎手の値の平均）。
- 追従 ρ = 8人の r*（A は固定値、B は最終手の値）と最後1000手の平均 r の Spearman 順位相関。

## 判定（本 seed 1000..1009、追試 seed 1100..1109、予備 seed 999。単位は世界＝10）

- **H_A_効く**：A の D < A0 の D が 10世界中 8以上。
- **H_A_追従**：A で ρ ≥ 0.7 が 8/10 以上、かつ A0 で ρ ≥ 0.7 が 2/10 以下。
- **H_B_効く**：B の D < B0 の D が 8/10 以上。
- **H_比べ**：同じ種で A の比 D_A/D_A0 と B の比 D_B/D_B0 を比べ、A の比が小さい世界が 8/10 以上なら「生まれつきの方が効く」、B が 8/10 以上なら「育ちの方が効く」、どちらでもなければ「差なし」。

本と追試は別々に判定し、どちらも同じ形で報告する（負けも）。線・数値・世界の作りは結果を見てから変えない。

## 発火の確認（本の前・安い設定で）

1. 決まった順で同じ種なら全記録の SHA が一致（2回走らせる）。
2. A と A0 で行動の列が実際に違う（同じなら同じものを測っている）。
3. r* = +0.8 だけの赤ちゃんと −0.6 だけの赤ちゃんで、予測が学べた後の選ぶ行動が違う。
4. B で r* が実際に動く（初期値0から離れる）。
5. 偏差の計算を手計算の小さな例と照合。
これらが通らなければ本に進まない。

## 言わないこと

これは「目標値つきの見られ方を予測で整える機構」が数値の上で働くかだけを見る。好かれたい気持ち・自己像・社会性・人格の証拠ではない。評価の作り（養育者の好み・赤ちゃん同士の「同じなら嬉しい」）は登録者が決めたもので、人間の社会の再現ではない。
