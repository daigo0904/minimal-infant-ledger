# S99 「見た手と同じなら褒められる」を手に依らず覚える頭なら、しきたりは代替わりしても残るか

なぜ：S98 ××。S95 を場面で分けると、新入りのしきたりは仲間の前で 0.154・養育者の前で 0.039 で、仲間の前でも 0.15 で頭打ち（診断.log）。
c を 300 にしても 0.16（選び.log）、承認そのものを報酬に足しても 0.13（選び2.log）。今の頭は「褒められるか」を手ごとに別々に覚えるので、「相手と同じ手なら褒められる」という一般則を持てない、と考えた。
頭.py＝写す頭：換算型に 同／違（見た手と同じ手／違う手をした時の評価を相手の見た目から予測する RLS 2つ）を足し、score[見た手] += kM·(同 − 違)。
世界.py＝S98 世界の写しに、選ぶ前に 子[i].見た手 を渡す1行。
- 調整（種 900〜909 のみ・選び3.log）：S95 の作りで kM=0 は S95 と同じ数字（0.098・仲間前 0.154）。kM=2 で 仲間前 0.744・養育者前 0.059。→ kM=2 を使う。
- 作り：S98 と同じ（2000〜 しきたり、4000〜 500手ごとに代替わり、寿命10000、褒める）。腕：kM 0／2 × しきたり 決まった手／でたらめ。
- 確かめ（種23399）：kM=0 は S98 と同じ sha ○、2000〜4000 で0〜6 全部しきたり ○、7500〜 強いる子なし ○、4腕が違う ○。確かめの1世界の kM=2 では 8500〜 全員のしきたり 0.043（残っていない）。
- 測る：8500〜10000 の全員がしきたりの手をする割合。効き＝決まった手 − でたらめ。
- 種：本 23200〜23229、追試 23300〜23329（各30世界・未使用）。
- H1 写す頭で代替わり後も残る：kM=2 で 効き > 0 が 20/30 以上
- H2 写す頭のほうが残る：効き kM=2 > kM=0 が 20/30 以上
- 勝ったら：世代をまたぐには「同じなら褒められる」の一般則が要る。負けたら：写し取りを強くしても、強いる者が消えると崩れる＝別の理由（食べ物への引き・入れ替わりの速さ）を調べる。
