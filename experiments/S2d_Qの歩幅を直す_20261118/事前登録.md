# S2d Q の歩幅を入力の大きさで割って測り直す（走らせる前に固定）

S2c の診断：Q の更新が入力の大きさ（|φ|²≈30）で割られておらず実効歩幅≈0.6、行動間の Q 差が赤ちゃんごとに ±2 揺れ（標準偏差最大1.2）、つながりの効き（0.10〜0.16）が埋もれていた。道具型・獲得型の両方に効く。
直すのは Q の更新を 学び率·δ·φ/|φ|²（学び率 0.05）にする1か所だけ。ほかは S2c と同一。
調整の種 900..902 で：道具型も養育者を喜ばせるようになった（喜ばせ 0.25→約0.6）。見られ分け差は獲得型 0.1〜0.2、道具型 0〜0.15。離乳後の喜ばせは道具型が 0.03〜0.12 に落ち、獲得型は 0.34〜0.42。
線（H1〜H4）は S2 と同一（H1 の「道具型 ≤0.05」は落ちうるがそのまま）。種：本 2600..2609、追試 2700..2709。
調整の回数の記録：S2 で4回、S2b〜S2d でそれぞれ不具合の修正1か所ずつ（どれも調整の種 900〜904 だけで確かめた）。
