# S2 育つ見られ分け — 「誰に見られているかで行動を変える」は育ちで身につくか

2026-11-18 登録（本・追試を走らせる前）。S1 の反省：S1 は「誰が見ているか」を番号で生まれつき渡していたので、見られ分けが最初の500手で完成していた（人間は何年もかかる）。

## 調整の記録（本の前・別の種 900〜903 で。本・追試の種は一度も走らせていない）
1. 空腹の報酬を「減った量」から「−空腹²」に変えた（上限1で止まると飢えた子が得をしていた）。
2. 見られ方の目標 r*（食べる直前の評価の平均）は赤ちゃんの評価で薄まり ≈0 になったので、獲得型の中身を「この見た目の相手に認められると食べられるか」の学習（つながり）に替えた。
3. 養育者の好む行動が無料だと誰が見ていても選べば済み、見られ分けが出なかった → 好む行動に空腹の代価 +0.01（よい子は疲れる）。
4. つながりの重み 0.5 では空腹の値打ちの揺れに埋もれた → 2.0。
世界.py はこの状態で固定（SHA を下に記す）。

## 世界（世界.py）
赤ちゃん8人＋養育者1人、寿命12000手、離乳8000手。毎手、各赤ちゃんを0.5で養育者・残りは他の赤ちゃんが見る。赤ちゃんに見えるのは相手の見た目（8次元・雑音0.6）だけで番号は知らない。
養育者の評価＝好み[a]（[−0.8,−0.2,0.3,0.9] の並べ替え）＋雑音。気に入り g は時定数5。**依存の世界**：離乳まで給餌確率 0.01+0.08·max(0,g)、離乳後0.05。**無関係の世界**：ずっと0.05。赤ちゃん同士の評価は S1 と同じ（相手の直前と同じなら+0.8、違えば−0.4）。一食0.3、代謝0.01、好む行動は+0.01。

## 頭（固定の乱数の感覚64＋線形）
- **道具型**：空腹だけ。SARSA（報酬 −空腹²、割引0.9、学び率0.02、探り0.1）。
- **獲得型**：道具型と同じ＋評価の予測（行動ごと RLS）＋つながり（見た目×受けた評価 → その後5手で食べたか、RLS 忘却0.9999）。選ぶ値＝Q＋2·つながり(見た目)·予測評価。
- **ランダム**：一様。

## 測るもの（10世界の各世界で8人平均）
見られ分け差 = 「養育者が見ている時に一番好かれる行動を選ぶ割合」−「他の赤ちゃんが見ている時に同じ行動を選ぶ割合」。
区間：初め=0〜500手、育った後=7000〜8000手、離乳後=10000〜12000手。喜ばせ=養育者が見ている時に一番好かれる行動を選ぶ割合。

## 判定（本 2000..2009、追試 2100..2109、世界=単位）
- **H1 見られ分けが出る**：依存×獲得型の育った後 ≥0.15 が 8/10 以上、かつ 依存×道具型の育った後 ≤0.05 が 8/10 以上。
- **H2 育つと出る**：依存×獲得型で 初め ≤ 育った後の半分 が 8/10 以上。
- **H3 世界しだい**：無関係×獲得型の育った後 < 依存×獲得型の育った後 が 8/10 以上。
- **H4 離乳後も残る**：依存×獲得型で 離乳後 ≥ 育った後の半分 が 8/10 以上、かつ 離乳後の喜ばせ 獲得型 > 道具型 が 8/10 以上。
本・追試を別々に判定し、負けも同じ形で出す。

## 言わないこと
残る（H4）は、つながりの忘却が遅い（0.9999）作りから来うる。「人間の承認欲求が残る仕組みと同じ」とは言わない。よい子の代価・給餌の形は登録者が決めた世界の作り。
