# S28 換算型（つながりを一食の値打ちで換算して足す）

S27：つながりの項は Q の物差しに換算されておらず、育つと Q に飲み込まれる。

- 換算型：score = q + c·max(v食,0)·u·ê。v食＝食べた次の手の TD 誤差の平均 − 食べなかった次の手の平均（時定数1000）。安いテストで 3000手後 v食 0.13〜0.41（正）、元と sha 違いを確認。
- c 選び（種 900〜909 だけ・選び.py）：c=3/10/30/100 で育った後 0.09/0.17/0.24/0.31。線「元の 0.17〜0.24 前後に届く」で c=30（10 は 0.169 で下端の手前）。
  なお調整の種でも 換算型 c=30 は初め 0.10 あり、v食が早く立つので初めの差は消えていない（記述）。
- 頭：S2d・感覚256・雑音0.3・寿命8000・離乳8000・依存。腕：道具型／元（獲得型 重み2）／換算型 c=30。
- 種：本 9000〜9009、追試 9100〜9109（未使用）。10世界中8以上で○。
- H1 差が育つ：（換算−道具）の見られ分けが 初め(0〜500) < 育った後(7000〜8000)
- H2 育ちで出る：換算型で 初め ≤ 育った後の半分
- H3 元に負けない：育った後 換算 ≥ 元
- 参考（判定外）：（元−道具）の差が育つ数
