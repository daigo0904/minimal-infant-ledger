# S170 失敗を見せる仲間がいれば、見て避けるか（調整で×・本計測なし・S169 の説明の訂正）

作り：世界.py＝S168 の写しに 何でも＝1（赤ちゃん1 はいつも手0＝取る、悪い物でも損をする＝失敗の見本）。数えるのは赤ちゃん1 以外。何でもなしは S168 と同じ sha ddcb99af ○、何でもで手が変わる ○、赤ちゃん1 が取る割合 1.0 ○。
調整（選び.log・種900〜909・4000〜4600）：悪いを取る 代理0 なし 0.044／あり 0.060、代理3 なし 0.056／あり 0.059。代理3＋何でも < 代理3のみ 2/10、< 代理0＋何でも 4/10。初めて悪いまで延びる 5/10。→ 見て避けるは出ない。
**前提の訂正**：悪い種類を取る割合はどの腕も 0.04〜0.06 で、探り（手の1割はでたらめ）だけで 0.1×1/4＝0.025、前半の古い悪い種類でも 0.03。v4 は「良いと分かった物だけ取る」ので、初めての物は見なくても最初から避けている＝避ける側に下げしろが無い。
→ S169 の「見本が成功例に偏るから損を避けない」は主因ではない見込み（偏りは事実だが、偏りが無くても下げしろが無い）。見て避けるを測るには、初めての悪い物が「取りたくなる見た目」（前に良かった物に似ている）の世界が要る（S171）。本計測は走らせない。
