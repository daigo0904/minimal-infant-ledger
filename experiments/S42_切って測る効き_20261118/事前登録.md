# S42 切って測るつながりの効き

S41：「換算−道具」の差は対照の頭の動きも拾う。→ 同じ赤ちゃんの中で、つながりの項を切った一生との差を「効き」とする。
- 一番の赤ちゃん（換算 c=30・Q 学び率 0.01・その手だけ・S16 世界・感覚256・雑音0.3）で v時定数 1000／5000。
- 各世界で3本：A 切らない／B 0〜500 だけ切る／C 7000〜8000 だけ切る（C は 7000手まで A と同じ＝本計測でも assert）。
- 効き 初め＝見られ分け(A) − 見られ分け(B)（0〜500）。効き 育った後＝見られ分け(A) − 見られ分け(C)（7000〜8000）。
- 発火の確かめ：B は 0〜500 で行動が違う、C は 7000手まで同じで 7000〜 で違う、v1000≠v5000。
- 種：本 11800〜11829、追試 11900〜11929（各30世界・未使用）。
- H1 効きが育つ：v5000 で 効き 初め < 育った後 が 20/30 以上
- H2 育ちが1000より大きい：（育った後−初め）v5000 > v1000 が 20/30 以上
