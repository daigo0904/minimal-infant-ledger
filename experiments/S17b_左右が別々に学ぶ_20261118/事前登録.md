# S17b 右脳・左脳が別々に学ぶと見られ分けは変わるか（走らせる前に固定）

S17 は出力（Q・評価の予測・つながり）を左右で共有していた。今回は左右それぞれが S2d の獲得型の学び手を丸ごと持つ（二つの脳.py）。右＝見た目の符号だけ（ざっくり）、左＝見た目そのまま（細かく）、各 64 tanh。空腹は同じ入力で左右とも同じに動く。
- **別々**：行動は左右の値の和で選ぶ（脳梁あり）。左右の学ぶ速さは同じ。
- **別々・右が速い**：右の Q の学び率3倍、右の評価の予測とつながりの忘れ 0.9999→0.999。
- **別々・脳梁なし**：毎手どちらか片方がランダムに選ぶ（左右の値を合わせない）。
- 対照：**共有見方**（S17 の見方）・**共有128**（S17 の一つ128）。
