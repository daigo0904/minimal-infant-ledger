# S19 自分の体を感覚に入れると漏れが増えるか・なぜか（走らせる前に固定）

S17（記述）と S18 で見えた向きを、新しい種で正式に確かめる。S17 の 脳.py をそのまま使う：**一つ128**（見た目だけ）／**一つ128体**（見た目＋空腹・直前に食べたか・直前の評価・直前の行動）。依存の世界・獲得型・雑音0.3・寿命8000。育った後＝7000〜8000手。種：本 6600..6609、追試 6700..6709。
- **H_漏れが増える**：P他 が 体あり > 見た目だけ の世界が 8/10 以上。
- **H_見られ分けが小さい**：見られ分け差が 体あり < 見た目だけ の世界が 8/10 以上。
- 診断（記述）：各手の選ぶ前の空腹を記録し、他の子が見ている手を空腹の上半分・下半分（その赤ちゃんの 7000〜8000 の中央値で分ける）に分けて P他 を比べる（両方の腕で）。

訂正（結果のあと・記述のみ）：空腹は上限1.0に張り付く手が多く中央値が1.0になり「上半分」が空（NaN）だった。診断は「空腹が上限(1.0)の手／それ未満の手」で分け直す（判定は変えない）。
