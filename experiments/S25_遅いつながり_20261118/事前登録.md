# S25 遅いつながり → 前提の訂正と、初めの差の出どころ

## 歩幅選び（種 900〜909 だけ・歩幅選び.py）
つながりを遅い学び（LMS）に替えても、初めの差（獲得型−道具型）は小さくならなかった。
歩幅 0.001 でも初めの差 0.049（RLS 0.059）、0.01 では 0.19 とむしろ大きい。
→「つながりを遅く学べば、つながりの分が育ちで出る」という前提は外れ（訂正）。本計測には進めない。

## 疑い：同点くずし
生まれた時 Q は全部 0 で、どの手も同じ値打ち。道具型は argmax が同じ手に張りつき見られ分けは 0。
獲得型は q + 重み·u·ê なので、u がどんなに小さくても、同点を ê（相手ごとの評価の予測）が崩す。
argmax は大きさを見ないので、つながりの小ささが効かない＝「つながりの分が初めからある」の正体ではないか。

## 判定（走らせる前に決める）
- 腕：獲得型 重み2（元）／獲得型 重み0.0001／道具型。S2d・感覚256・雑音0.3・寿命8000・離乳8000・依存。
- 種：本 8400〜8409、追試 8500〜8509（未使用）。10世界中8以上で○。
- H1 同点くずし：初め(0〜500)の（重み0.0001 − 道具型）が、（重み2 − 道具型）の半分以上
- H2 大きさは育った後に効く：育った後(7000〜8000)の見られ分けが 重み2 > 重み0.0001
- 読み：H1○H2○なら、初めの差は同点くずし（大きさに依らない）、育った後の差はつながりの大きさの分。
- 確かめ：重み0.0001 と 重み2 で一生が違う（sha）。
