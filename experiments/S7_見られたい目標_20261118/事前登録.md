# S7 見られたい目標（ホメオスタシス）は、欠乏と飽和で行動を変えるか（走らせる前に固定）

本人の最初の案「相手からどう見られたいかのホメオスタシス」を、S2d の獲得型の上に戻す。
- **目標型**＝獲得型＋「大事な相手からの見られ方 r_c」と「見られたい目標 r*」。大事さ c＝clip(つながり(見た目)/0.05, 0, 1)。r_c ← r_c + (c·e − r_c)/50、r* ← r* + (r_c − r*)/5000。選ぶ値に 2·c·(r* − r_c)·予測評価 を足す（見られ足りないと喜ばせ、見られすぎると控える）。
- **獲得型**＝S2d と同じ（目標なし）。どちらも つながりの忘却 0.9999・感覚256・雑音0.3。

なぜ「離乳後に残るか」で測らないか：目標も「誰が大事か」の遅い記憶に頼るので、残るのは作りから（S5b と同じ形になる）。代わりに、ホメオスタシスにしかない性質で測る：**欠乏で増え、飽和で減る**（人の子で、しばらく大人と接しないと社会的な承認への反応が強まり、浴び続けると弱まる報告がある：Gewirtz & Baer 1958・要旨のみ・未確認）。

世界：依存の世界、離乳8000（以後の給餌は見られ方と無関係）、寿命8700。8000〜8500手に試しの区間：**普通**／**欠乏**（養育者が来ない：その番を隣の赤ちゃんに置きかえ）／**飽和**（養育者がいつも見る。評価はいつもどおり）。それ以外の乱数は3つで同じ（8000手までの行動列が一致することを確かめた）。
測るもの：戻ってすぐ（8500〜8600手）の P養（養育者が見ている時に一番好かれる行動を選ぶ割合、8人平均）。
調整の記録（種900〜903）：①飽和を最初「何をしても褒める」にしたら、評価の予測が平らに学び直されて獲得型でも下がった（混ざり）→「いつも見る」に替えた。②窓を200手（8500〜8700）にしたら差が見えなかった。中を見ると欠乏で r_c が 0.247→0.071 に下がり、戻って50手で 0.194 に回復していた → 窓を100手にした。目標重み・時定数は最初の値のまま。

判定（本 4000..4009、追試 4100..4109）：
- **H_欠乏_目標型**：目標型で 欠乏 − 普通 > 0 が 8/10 以上、かつ中央値 ≥ 0.05。
- **H_欠乏_獲得型（対照）**：獲得型の 欠乏 − 普通 の中央値 < 0.05。
- **H_飽和_目標型**：目標型で 普通 − 飽和 > 0 が 8/10 以上、かつ中央値 ≥ 0.05。
- **H_飽和_獲得型（対照）**：獲得型の 普通 − 飽和 の中央値 < 0.05。
