# S233 話す理由から「耳で話す」が生まれるか：耳で話すかどうかを型として受け継がせる

S229：耳で話す（聞いて分かる言い方で話す）を決まりとして入れると、話す理由（共感）が無くても言葉ができた。では、耳で話す子は、自分で増えていけるか。
作り：世界.py＝S232 の写しに 話し方＝'型'（子ごとの印 耳）。(1) 選び替え：はじめ子0〜3 が耳、2000手から250手ごとに一番お腹を空かせた子を新しい頭に、印は一番お腹の空いていない子から受け継ぐ（S205 と同じ）。終わり＝最後の8回の耳の子の数。共感あり／共感なし。(2) 型固定（選び替えなし）：耳4・ふつう4、席を入れ替えた2一生、後半8000手の空腹 ふつう−耳（正＝耳が得）。毎回組み替え。
- 確かめ：口を閉じれば S232 と同じ sha ○、全員耳の型は「耳で話す」と同じ sha ○。
- 調整（選び.log・種900〜909）：終わりの耳の子 共感あり 10世界とも 0、共感なし 0（1世界だけ 1.1）。型固定の空腹差 ふつう−耳 −0.002〜−0.009（中央値 −0.005、10世界とも負＝耳の子が少し損）。
- 理由の見込み：耳で話しても話し手自身は食べない。得をするのは聞き手で、聞き手は耳の子でもふつうの子でも同じように得をする。耳の子が自分だけ得をする道が無い（恩・評判・同じ型どうしで組む、が無い）。少し損をする理由は未検証（耳の決まりが自分の点と違う手を出すので、話し手の時の学び方がずれる、が候補）。
- 見込み：耳の子は増えない（H1 ×・H2 ×）、得をしない（H3 ×）、むしろ少し損で（H4 ○）、消える（H5 ○）。＝言葉を作る話し方は、話す理由（自分の得）が無いと、受け継がれていかない。
- 種：本 48200〜48229、追試 48300〜48329（未使用）。
- H1 共感ありで耳の子が増える：終わり > 4 が 20/30 以上（見込み ×）
- H2 共感なしより多い：終わり 共感あり > 共感なし が 20/30 以上（見込み ×）
- H3 耳の子は得：型固定で ふつう−耳 > 0 が 20/30 以上（見込み ×）
- H4 耳の子は損：型固定で ふつう−耳 < 0 が 20/30 以上（見込み ○）
- H5 耳の子は消える：共感ありで 終わり = 0 が 20/30 以上（見込み ○）
