# S186 v4 のどの部品が余韻を消すか

S185：記憶0.5 で、元の頭には余韻（養育者が去った直後に好きな手が多い）が出るが、v4 には出ない。
作り：S185 の世界・頭をそのまま読む。v4 から部品を1つずつ戻す腕。
- 調整（選び.log・種900〜909）：余韻（>0）：元 +0.109（10/10）、v4 −0.013（3/10）、λ1 +0.018（10/10）、kf0 +0.049（10/10）、kD0 −0.005（3/10）、kJ0 −0.013（3/10・v4 と同じ sha＝この世界では共同注意が起きず kJ は働かない）、損もなし −0.009（2/10）。
- 見込み：余韻を消しているのは 食べ予測（kf）と 癖の重みの小ささ（λ0.2）の2つ。食べ予測が「今の場面で何が食べ物につながるか」を強く押すので、記憶にある「さっき大人がいた」より今の見た目が勝つ。
- 種：本 38800〜38829、追試 38900〜38929（未使用）。腕：v4／kf0／λ1／kf0＋λ1（すべて記憶0.5）。kf0＋λ1 は調整していない（見るだけ）。
- H1 食べ予測を切ると余韻：kf0 で 余韻 > 0 が 20/30 以上
- H2 癖を戻すと余韻：λ1 で 余韻 > 0 が 20/30 以上
- H3 食べ予測のせい：余韻 kf0 > v4 が 20/30 以上
- H4 癖の重みのせい：余韻 λ1 > v4 が 20/30 以上
