# S46 無関係の世界でつながりが喜ばせる方へ押す理由（記録の診断）

S45 の作り（無関係の世界・我慢の代価0・v時定数5000・Q 学び率0.01・換算 c=30・その手だけ・S16 世界）。選ぶ時の u（つながり予測）・v食・ê差（一番の手 − 他の手の平均）を、養育者が見ている手／他の子が見ている手に分けて記録（記録しても sha 同じ・一番の手の一致を確認）。
- 種：本 12600〜12629、追試 12700〜12729（各30世界・未使用）。育った後＝7000〜8000。
- H1 u養が正：育った後の u(養育者) > 0 が 20/30 以上（食べ物と無関係なのに「認められると食べられる」と覚えている）
- H2 u養が他より大：u(養育者) > u(他の子) が 20/30 以上
- 走らせる前の見立て：無関係の世界では食べ物はどの行動とも独立なので、u は揺れだけで符号は世界ごとにばらつくはず（H1 は × と予想）。それでも見られ分けが正に偏るなら、u 以外（v食 の正の偏り×ê差 の大きさ、あるいは u の符号と ê差 の向きの組み合わせ）を疑う。
